# Features of @plutocms/syntax-lowlight

- Code highlighting with lowlight: the highlighter `lowlight` (`definePlutoHighlighter` of core) colors the code blocks of the public API with the `common` grammars of highlight.js and their aliases, on the server and in a static build; a block in another language stays plain; the opt-in `@plutocms/syntax-lowlight/theme.css` colors the `hljs-*` classes of `.pluto-prose` with `--pluto-code-*` variables, light and dark: @../../../../.claude/skills/content-model/SKILL.md
