# Features of @plutocms/blocks

- A landing kit of 22 blocks for pages (`block-section`, `block-columns`, `block-column`, `block-heading`, `block-text`, `block-image`, `block-button`, `block-icon`, `block-divider`, `block-spacer`, `block-video`, `block-icon-list`, `block-icon-box`, `block-image-box`, `block-accordion`, `block-testimonial`, `block-counter`, `block-social-icons`, `block-gallery` and the items), as content components with `definePlutoBlock`, so the block editor palette and inspector work: layout blocks take blocks in their slots (`accepts`), a heading has an inline slot, a text block a rich slot; plain CSS with low specificity and CSS variables (`--pluto-blocks-*`); a theme in `app.config.ts` (`plutoBlocksTheme`: colors and fonts) written as `:root` variables on the server too; real `h1` to `h6`, links as `<a>`, an accordion of `<details>`, images that keep their `alt`: @../../../../.claude/skills/blocks-kit/SKILL.md
