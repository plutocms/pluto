# Features of @plutocms/wordpress

- A CLI (`pluto-wordpress import <file.xml|page.json> [--out <dir>] [--dry-run] [--no-media] [--force]`) that imports the Elementor landing pages of a WordPress site into a Pluto Git CMS project, as pages made of `@plutocms/blocks` blocks: a WXR reader (CDATA, PHP-serialized metas, the JSON of `_elementor_data`), the modern flex `container` and the legacy `section` / `column`, 19 widgets mapped to blocks (a shortcode and every other widget become a placeholder and a report entry), Font Awesome icons mapped to Lucide, kit colors as tokens and literal colors kept exact, sizes rounded to the kit scale with each rounding reported, the Elementor kit built into `plutoBlocksTheme` (`pluto-import/theme.json` and an `app.config.ts` snippet), image download into the media library with the same file and record as the GitHub media driver (a timeout, a 20 MB limit, an `image/*` check, reuse by source URL), `content/pages/<path>.md` with `wordpress: { id, link }`, a dry run, a re-run that skips a page with the same WordPress id (`--force` writes it again), WordPress menus as `content/menus/<handle>.md` (nested `menu-item` blocks, the primary menu as `main`), the Elementor footer (Header Footer Elementor or a theme builder template) as `content/areas/footer.md` (a navigation menu widget as an icon list, a site logo, a site title, a copyright), the header as a report entry, and a report (`pluto-import-report.md`): @../../../.claude/skills/wordpress-import/SKILL.md
